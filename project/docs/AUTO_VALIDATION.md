# Auto Validation — CLI, GUI, and MCP

This document describes the production automation layer that discovers datasets,
runs load → preprocess → reconstruction → ROI → tumor-candidate checks, and
writes an **operational analysis report**.

The mentor guide and beginner explainer are **separate reference documents**.
They are not generated by Auto Validation.

## Architecture (short)

```
roots → discovery → resolver (metadata↔measurement, BMID tumor+healthy strategy)
      → cached pipeline checks → threshold classifier (strict/balanced/lenient)
      → Auto Analysis markdown + JSON evidence + showcase figures
```

Facades:

- `automation.service.AutoValidationService` — reusable core
- `tools/run_auto_validation.py` — CLI
- Acquisition **Run Auto Validation** — GUI one-click
- `automation/mcp_server.py` — lightweight stdio MCP tools

## Quality profiles

| Profile | Intent |
|---------|--------|
| `strict` | Tight localization/SCR/confidence gates |
| `balanced` | Default demo / tumor-detection screening |
| `lenient` | Diagnostics / first-pass triage |

Each result includes: `status`, numeric metrics, human reasons, remediation,
tumor-candidate Yes/No, and `recommended_upload`.

## CLI usage

```bash
cd project
python tools/run_auto_validation.py --profile balanced
```

Default roots are `umbmid/simple-clean` (if present). Default scan set is a **diverse subset** (~8 scans: healthy + size/severity/location variety), not all 2264.

Full inventory (slow):

```bash
python tools/run_auto_validation.py --bmid-strategy all --max-bmid-scans 0 --max-files 20
```

Faster load-only:

```bash
python tools/run_auto_validation.py --roots datasets --no-reconstruction --max-files 10
```

## GUI one-click usage

1. Start app: `python main.py`
2. Open **Acquisition**
3. Leave the scope on **Periodic test (8 diverse scans)** unless you really want the full inventory
4. Click **Run Auto Validation** (use **Cancel Auto Validation** if it was started by mistake)
5. Watch the **Log** panel
6. Read the analysis popup; `latest_auto_analysis.md` opens automatically
7. The best tumor-candidate case is loaded and reconstructed in the GUI

Existing Load → Preprocess → Reconstruct workflows are unchanged. Intermediate outputs are in Preprocessing **Stages** / **Time (IFFT)** and Reconstruction **Time (IFFT)** / **Steps**.

## Generated report locations

- `results/latest_auto_analysis.md` — operational analysis (detection table, tumor index, showcase images)
- `results/latest_auto_validation.json` — machine-readable evidence
- `results/latest_auto_selected.png` / `_beamformers.png` / `_roi_refine.png` — showcase figures

These files are overwritten in place on each run.

## Disclaimer

Model / reconstruction output is **not a clinical diagnosis**.
